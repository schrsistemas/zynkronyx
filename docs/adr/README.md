# Architecture Decision Records

ADRs capture decisions with meaningful architectural trade-offs. They are immutable historical records; superseding decisions create a new ADR.

## Required sections
- Context
- Decision
- Alternatives considered
- Consequences
- Security impact
- Operational impact
- Rollback/recovery
- Metrics
